# Scientific-Benchmarking-Engineering-Quality-Evaluation-of-Electric-Vehicle-Concepts
Dieses Tool beschreibt eine objektive und kostenneutrale Methode zum simulativen Benchmarking von Elektrofahrzeugen, indem Fahrzeugparameter in Kombination mit Durchschnittsparametern ein Referenz-Simulationsmodell entwickeln, welches mit den realen Ergebnissen verglichen wird.
